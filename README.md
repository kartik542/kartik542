# My Web Development Mini Projects

This repository contains **four small web projects** demonstrating skills in **HTML, CSS, JavaScript, jQuery, and Bootstrap**. Each project is standalone and showcases different features of web development.

---

## Projects Overview

### 1. **CarLandingPage (MiniProject)**
- **Technologies:** HTML, CSS, JavaScript, jQuery, Bootstrap  
- **Description:** A sleek landing page for a car project, showcasing a responsive design and interactive elements using jQuery and Bootstrap.  

### 2. **Image_Gallery**
- **Technologies:** HTML, CSS, JavaScript  
- **Description:** A dynamic image gallery that allows users to view images in a structured layout. Includes hover effects and image navigation.  

### 3. **Portfolio**
- **Technologies:** HTML, CSS, JavaScript  
- **Description:** A personal portfolio template featuring smooth animations and a professional layout to showcase skills, projects, and contact information.  

### 4. **Calculator**
- **Technologies:** HTML, CSS, JavaScript  
- **Description:** A functional web-based calculator that performs basic arithmetic operations with a clean and responsive design.
